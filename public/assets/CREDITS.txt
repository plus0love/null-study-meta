Null Study Meta — 에셋 출처 / 제작자 / 라이선스
================================================

이 폴더의 tiles.png / player.png 는 tools/build_assets.py 가 아래 원본을 가공(리컬러·크롭·2배 확대)하고
직접 그린 소품을 합쳐 만든 파생물입니다. 원본은 tools/fetch_assets.py 로 받습니다.

1. Roguelike Indoors (타일셋)
   - 제작자: Kenney (Kenney Vleugels, www.kenney.nl)
   - 출처:   https://kenney.nl/assets/roguelike-indoors
   - 라이선스: CC0 1.0 (Public Domain) — 상업적 이용 가능, 크레딧 선택 사항
   - 사용 부분: 의자 4방향, 카운터, 액자, 작은 화분 (tools/recolor.py 로 목업 팔레트에 맞춰 리컬러)

2. Zelda-like tilesets and sprites (캐릭터)
   - 제작자: ArMM1998
   - 출처:   https://opengameart.org/content/zelda-like-tilesets-and-sprites
   - 라이선스: CC0 1.0 (Public Domain)
   - 사용 부분: gfx/character.png 의 4방향 걷기 4프레임(16x32). 머리색 → 흑발, 셔츠 → 흰색으로 리컬러 후 2배 확대

3. 오리지널 픽셀아트 (이 저장소, tools/props.py · props_room.py · props_v2.py 로 코드 생성)
   - 바닥/벽/창문(야경·펜던트), 대형 칠판·세로 보드·유리 패널, 큰 책장·좁은 책장·사다리 선반,
     소파·둥근 테이블·스탠드 램프·강아지, 커피머신·메뉴보드·진열장, 푸프, 모니터 책상·협탁,
     유리 파티션·미닫이문·STUDY 패널, 화이트보드·회의 테이블, 입구 이중문·가로등·벤치·화단·표지판·매트, 러그류, 3x5 픽셀 폰트
   - 강아지 쿠션(cushion)은 tools/sprites/cushion.png (poodle_cushion.png 에서 쿠션 부분만 분리, 오리지널)
   - 강아지 NPC 시트 dog.png (16x24 논리 → 32x48, 6행 x 2프레임: 걷기 4방향·앉기·자기) 는 tools/dog_sprite.py 로 생성.
     푸들 머리·팔레트는 tools/sprites/poodle_cushion.png (오리지널) 에서, 몸통·다리·꼬리·옆모습·자는 모습은 코드로 직접 그림
   - 라이선스: 프로젝트 라이선스를 따름

4. UI 라인 아이콘 (public/index.html 의 인라인 SVG <symbol>) — 이 저장소에서 직접 그린 오리지널 (24px 그리드, stroke 기반)
   이모지(상태 아이콘·리액션)는 사용자 시스템 이모지 폰트로 렌더링 (별도 에셋 없음)
