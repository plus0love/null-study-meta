Null Study Meta — 에셋 출처 / 제작자 / 라이선스
================================================

이 폴더의 tiles.png / player.png 는 tools/build_assets.py 가 아래 원본을 가공(리컬러·크롭·2배 확대)하고
직접 그린 소품을 합쳐 만든 파생물입니다. 원본은 tools/fetch_assets.py 로 받습니다.

1. Roguelike Indoors (타일셋)
   - 제작자: Kenney (Kenney Vleugels, www.kenney.nl)
   - 출처:   https://kenney.nl/assets/roguelike-indoors
   - 라이선스: CC0 1.0 (Public Domain) — 상업적 이용 가능, 크레딧 선택 사항
   - 사용 부분: 의자 4방향, 카운터, 액자, 작은 화분 (tools/recolor.py 로 목업 팔레트에 맞춰 리컬러)

2. Zelda-like tilesets and sprites (캐릭터)
   - 제작자: ArMM1998
   - 출처:   https://opengameart.org/content/zelda-like-tilesets-and-sprites
   - 라이선스: CC0 1.0 (Public Domain)
   - 사용 부분: gfx/character.png 의 4방향 걷기 4프레임(16x32). 머리색 → 흑발, 셔츠 → 흰색으로 리컬러 후 2배 확대 (player.png)
   - 5단계 (tools/avatar_parts.py): 같은 프레임을 팔레트·위치 기준으로 레이어 분리 → public/assets/avatar/ 의
     body/base.png(피부·발밑 그림자, 머리 자리는 직접 그린 민머리 두상), hair/basic.png(원본 머리), top/basic.png(튜닉+벨트),
     bottom/pants.png, shoes/boots.png. 색은 클라이언트가 런타임에 팔레트 치환(기준 톤은 원본 색 유지)

3. 오리지널 픽셀아트 (이 저장소, tools/props.py · props_room.py · props_v2.py · props_v3.py 로 코드 생성)
   - 바닥/벽/창문(밤 야경 3프레임 + 낮 건물, 하늘은 클라이언트 그라데이션, 펜던트), 대형 칠판·세로 보드·유리 패널, 큰 책장·좁은 책장·사다리 선반,
     소파·둥근 테이블·스탠드 램프, 커피머신·메뉴보드·진열장, 푸프, 모니터 책상·협탁,
     유리 파티션(차콜 프레임 기둥 + 반투명 유리 판)·슬라이딩 문 패널·열린 문 레일, 작은 수납장·벽 선반(책·화분),
     화이트보드·회의 테이블, 입구 이중문·가로등·벤치·화단·표지판·매트, 러그류, 3x5 픽셀 폰트
   - 강아지 쿠션(cushion)은 tools/sprites/cushion.png (poodle_cushion.png 에서 쿠션 부분만 분리, 오리지널)
   - 강아지 NPC 시트 dog.png (16x24 논리 → 32x48, 6행 x 2프레임: 걷기 4방향·앉기·자기) 는 tools/dog_sprite.py 로 생성.
     푸들 머리·팔레트는 tools/sprites/poodle_cushion.png (오리지널) 에서, 몸통·다리·꼬리·옆모습·자는 모습은 코드로 직접 그림
   - 아바타 추가 파츠 public/assets/avatar/ (tools/avatar_parts.py, 원본 캐릭터 규격 16x32·4방향 4프레임, 화풍 규칙에 맞춰 16px 마스크로 직접 그림):
     hair/ short·part·curly·spiky·bob·long·ponytail·twintail·bun·cap(네이비 야구모자)·beanie(머스터드 비니) 11종,
     top/ tshirt·shirt(흰 카라·단추)·hoodie(후드·끈·주머니)·knit(터틀넥·케이블·밑단) 4종 (원본 튜닉 레이어를 프레임별로 가공),
     acc/ glasses_round·glasses_square·sunglasses 3종, body/base.png 의 민머리 두상(4방향)
   - 9단계 가구 상점 스프라이트 public/assets/furniture.png/json (tools/furniture.py, 16px 논리 → 2배, 같은 팔레트):
     책상 소품 12종(머그컵 5색·작은 화분·연필꽂이·포스트잇·탁상 램프 3종·미니 피규어·탁상 액자·향초 2프레임·듀얼 모니터·기계식 키보드 4프레임·미니 스피커·어항 3프레임),
     공용 가구 11종(벽 포스터 5종·쿠션 6색·작은 러그(회전)·스탠드 조명·벽시계 3종·책장 채우기·라운지 담요·커피머신 업그레이드 3프레임·빈백·안마의자 2프레임·침대 3색(회전·이불 오버레이)),
     아이콘 32x32 42장 — 전부 코드로 직접 그린 오리지널 (커피머신 업그레이드의 뒤 선반은 props.backbar_upper 재사용)
   - 라이선스: 프로젝트 라이선스를 따름

4. UI 라인 아이콘 (public/index.html 의 인라인 SVG <symbol>) — 이 저장소에서 직접 그린 오리지널 (24px 그리드, stroke 기반)
   이모지(상태 아이콘·리액션)는 사용자 시스템 이모지 폰트로 렌더링 (별도 에셋 없음)
   뽀모도로 알림음은 Web Audio 로 합성 (public/js/fx.js, 오디오 파일 없음)
   유튜브 카드는 YouTube IFrame Player API (https://developers.google.com/youtube/iframe_api_reference) 를 런타임에 로드 — 영상 콘텐츠는 사용자가 고른 것으로 저장소에 포함되지 않음
